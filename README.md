# Bilad / بلاد

A single full-screen page with the BILAD wordmark, inverted L, intact Malwiya tower, and Arctic Depths background, based on the supplied references.

Run `npm install` and `npm run dev` to preview. `npm run build` exports the production website to `out/`.

The tower image is supplied by the user. The layout adapts to desktop and mobile without scrolling or additional controls.
